# Site romântico

Rodar:

    npm install
    npm run dev

Gerar versão para publicar:

    npm run build

Troque os arquivos de exemplo pelos seus em:

    public/assets/photos/   (jpg)
    public/assets/videos/   (mp4)
    public/assets/music/    (mp3)

Depois ajuste os nomes e legendas em src/data/media.js.
